# Plans and specs

Plans and specs for larger changes live here, one file each, numbered in the order they were written (`0001-short-name.md`). A plan states the goal, the ground rules, the design, the tests and the order of work, and it is short enough to read in a few minutes. Every plan has a tracking issue on GitHub, linked from its file and, while the plan is open, listed at the end of this page; the issue holds the task list and the plan file holds the design. Move its status from "proposed" to "in progress" to "done" as the work moves, and delete or fold a plan into the guides once its work is complete.

Playwright planner output (see `CLAUDE.md`) goes in `specs/` at the repository root, not here.
