# Attributions

The reference host bundles no datasets. Its basemaps and its open data layers use third-party services, fetched by the browser only when someone turns a layer on.

Checked on 2026-11-11 for the half-hourly layer: GIBS answers a tile with `Access-Control-Allow-Origin: *` and no key, as a 256 px PNG of about 1 to 10 KB, for levels 0 to 6, and names a half hour by `YYYY-MM-DDTHH:MM:SSZ`. A half hour first answered between about 5 hours 45 minutes and 6 hours 10 minutes after it started (14:30 UTC was there at 20:14 UTC; 15:00 UTC was a 404 at 20:48 and answered by 21:09), and the capabilities document listed a newest time an hour behind the tiles, so the app offers half hours up to seven hours back, worked out from the clock. GIBS reports the Early run (`v7_NRT`) for half hours from at least September 2025 on, and the Final run (`v7_STD`) for June 2025 and before. Tiles answer back to 1998-01-01 00:00 UTC (1997-12-31 answers 404), although the capabilities document lists times from 2026 only, so the layer offers half hours from 1998-01-01.

NASA data is openly shared; its data use guidance says NASA material may not be used to suggest or imply endorsement by NASA, and the app uses no NASA logo. The GIBS acknowledgement is the full wording from the GIBS "Data Use Guidance and Acknowledgements" page. GDACS alerts are automatic model outputs and the app says so on every card. The Copernicus CEMS-FLOODS licence asks for "Generated using Copernicus Emergency Management Service information [Year]" and says the data is for information only. In the definition `{year}` stands for the current year, filled in when the credit is shown; confirm both texts on the current licence pages before release.

OpenStreetMap data is available under the [Open Database Licence](https://opendatacommons.org/licenses/odbl/). Use of the OpenStreetMap tile servers follows the [tile usage policy](https://operations.osmfoundation.org/policies/tiles/). OpenTopoMap's [about page](https://opentopomap.org/about) allows its tiles to be used while the server is not overloaded by mass downloads, gives no availability guarantee and asks to be told of use. The credit there reads "Kartendaten: © OpenStreetMap-Mitwirkende, SRTM | Kartendarstellung: © OpenTopoMap (CC-BY-SA)" and is shown in English. The map displays the active provider's attribution, followed by MapLibre's.

EOX's [non-commercial licence page](https://cloudless.eox.at), checked on 2026-11-11, puts the 2018 to 2025 layers under CC BY-NC-SA 4.0, "free to use for non-commercial purposes, provided appropriate attribution is given", and gives the credit "EOxCloudless https://cloudless.eox.at by EOX IT Services GmbH (Contains modified Copernicus Sentinel data 2025)", to be shown legibly near the map and with its links online. The site shows it word for word, with the licence, and a saved image keeps the text, address included. The tiles come from EOX's free demo service ([maps.eox.at](https://maps.eox.at)), whose page, checked on 2026-11-11, says "Just feel free to use them. We just ask for a link back to EOX::Maps as well as appropriate attribution", with the respective links, so the credits link to EOX::Maps too. The same page says the demo service "is provided as is without any guarantee" and that rate limiting applies; when the imagery cannot be loaded the site marks Satellite unavailable and goes back to the previous basemap. The tile address names the layer's year, and so does the credit: both change together when the site moves to a newer layer. EOX's labels overlay has only that informal permission, not a named licence, so the place names and roads come from OpenFreeMap instead. The reference site is a public, non-commercial project, which is what the licence allows; the SDK never carries this source, so an app built on it for commercial use is not bound by it, and the WebMCP basemap tool does not offer Satellite, because an agent should not accept a provider's licence on a person's behalf.

The reference site offers these six basemaps: Bright, Positron, Streets, Topographic, Satellite and Dark. Topographic and Satellite are defined by the host in `packages/web/src/basemaps`, not by the SDK: Topographic so an app built on the SDK sends no traffic to a volunteer-run server unless its own host chooses to, and Satellite because its imagery's licence is non-commercial. The SDK in `packages/core` defines seven basemaps: Bright, Positron, Dark, Liberty and Fiord (OpenFreeMap), Streets, and Colorful (a pre-built style from [VersaTiles](https://versatiles.org)), which the site does not offer and does not load from. A host that offers Colorful carries VersaTiles' own credit terms, including the ESA WorldCover credit for its land cover tiles, which the SDK's definition holds.

## Place search

Place search and reverse geocoding use [OpenStreetMap Nominatim](https://nominatim.org), with © OpenStreetMap contributors attribution. Suggestions as you type in the search box use [Photon](https://photon.komoot.io), a geocoder run by komoot on OpenStreetMap data, with © OpenStreetMap contributors attribution under the [Open Database Licence](https://opendatacommons.org/licenses/odbl/).

## Routing

Routes and travel-time areas come from the public [Valhalla](https://valhalla.github.io/valhalla/) routing service at `valhalla1.openstreetmap.de`, run by the [FOSSGIS](https://www.fossgis.de) community. Valhalla is open source under the MIT licence, and it routes on OpenStreetMap data, with © OpenStreetMap contributors attribution under the [Open Database Licence](https://opendatacommons.org/licenses/odbl/).
